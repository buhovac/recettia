## Problèmes et solutions

- **PHP 8.3 au lieu de 8.4** : Git Bash trouve le PHP de Laragon (8.3.12), PowerShell celui de Herd (8.4.27). Git Bash ne sait pas lancer le `php.bat` de Herd sous le nom `php`. Solution : `~/.bashrc` (chargé par `~/.bash_profile`) place `herd/bin/php84` en tête du PATH, pour Git Bash seulement. Le PATH Windows et Laragon ne changent pas. À adapter si Herd passe à une autre version.
- **Modèle par défaut coûteux** : sans réglage, `laravel/ai` utilise `anthropic/claude-sonnet-5.5` pour OpenRouter. Solution : `models.text.default` dans `config/ai.php`.
- **Variable `.env` vide** : `OPENROUTER_MODEL=` donne une chaîne vide, et `env()` ignore alors la valeur par défaut. Solution : `env('OPENROUTER_MODEL') ?: 'openai/gpt-6-luna'`, et pareil pour le timeout.
- **Coût absent de l'objet `usage` du SDK** : `TextUsage` ne garde que les jetons. Solution : lire `usage.cost` dans la réponse brute (`$response->raw`) et demander `usage.include` à OpenRouter.
- **Erreurs vue-tsc sur `.form()` dans des fichiers du kit** : `php artisan wayfinder:generate` lancé à la main, sans l'option des formulaires. Solution : `npm run build` régénère correctement les fichiers. Ne pas lancer cette commande seule.
- **Tests d'erreur classés « indisponible » à tort** : Pest exécute les closures d'un jeu de données, donc une closure imbriquée devient l'exception elle-même. Solution : une seule closure par valeur.

- **Allergène oublié (poisson dans le nuoc-mâm)** : le modèle ne regardait que les ingrédients qui sont eux-mêmes des allergènes. Solution : la consigne demande de vérifier les produits transformés.
- **Faux positif (pignons de pin comptés en fruits à coque)** : le modèle utilisait le sens courant de « nuts ». Solution : la consigne donne les définitions du règlement UE pour nuts, gluten, milk et sulphites.
- **DeepSeek tronqué** : son raisonnement a pris les 3 000 jetons de sortie et la réponse est arrivée incomplète. Le validateur l'a rejetée et le coût a été journalisé : les garde-fous ont fonctionné.
- **Risque accepté par Anyssa** : sans quota, un compte peut épuiser la clé à 0,50 $. La limite de la clé bloque tout dépassement.
